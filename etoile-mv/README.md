# Étoile — 恋する乙女は、痩せて最高の私へ。 15秒 MV

女性専用パーソナルジム Étoile のキービジュアル（`assets/reference.webp`）1枚から作った 15 秒のリリックビデオです。
作り方は `koi-mv/` と同じで、`render(t)`（時刻 → 画面）を HTML / CSS / JavaScript で描き、音は WebAudio で合成しています。
キャラクターは MiniMax H3 で緑一色の背景の上に生成した 15 秒の映像を切り抜いて重ねます（映像が無いときは原画から切り抜いた静止画で代用）。

- 完成動画: `dist/etoile.mp4`（1920×1080 / 30fps / 15.0秒）
- ブラウザで見る: `index.html` を開いてクリック（またはスペースキー）で再生。`index.html?t=4` で任意時刻の静止画

## 構成（128 BPM・8小節＝1小節1シーン）

Web プロモーション用。音なしの自動再生でも伝わるよう、要の言葉はすべて大きな文字で出し、最後は無料カウンセリングへの導線で終わります。

| 時刻 | シーン | 見せ方 |
| --- | --- | --- |
| 0.0–1.9 | HOOK | 1コマ目から彼女と見出し。「恋する乙女は、／痩せて／最高の私へ。」を拍ごとに叩きつけ、左の縦線を「駅」に見立てて1行ずつ点灯。「せ」に飛び込むズームで次へ |
| 1.9–3.6 | START | 発車メロディ。「START 9.01／今日から／私の未来が／変わりはじめる。」を START の枠で囲み、上に「9月から始まる…旅。」。足元を誘惑・停滞期が通過 |
| 3.6–5.6 | 発車案内板 | 横に振るカメラで紺の案内板が入り、6つの壁（誘惑〜体重）が1行ずつパタパタ表示され、説明文が流れる |
| 5.6–7.5 | どん底 | 色が沈み、ドラムが心音だけに。むくみ・自己嫌悪・リバウンド不安の本音が3枚重なり、駅名が縦に降る |
| 7.5–9.4 | 転機 | 白フラッシュ → 顔のアップ（顔を上げて拳を握る）、放射線と「MY FUTURE IS MINE.」。「わたしを／あきらめない。」「この一歩が、／未来を変える。」 |
| 9.4–11.4 | 支える駅 | 「次の駅は、」＋白帯の「理想の私。」、「一緒に、乗り越えよう。」。完全女性専用・パーソナル指導・食事サポート・手ぶらOK が次の駅として足元で点灯 |
| 11.25–13.0 | GOAL | クリスマスの電飾と雪。枠が描かれ 12.19 秒に「12.25 X'mas」と星。「最高の笑顔で／大切な人と特別な日を。」 |
| 13.0–15.0 | エンドカード | 星のワイプ。ブランド、特徴4つ、「無料カウンセリング受付中」ボタン（拍ごとに脈打つ）、アクセス、GOAL バッジ。彼女は歩き続ける |

画面の文字はすべてキービジュアルにあるものだけです（改行位置のみ調整）。音は -13.1 LUFS / ピーク -1.6 dBFS。

## メイキング（making.html・30秒）

`dist/making-of.mp4`（1920×1080 / 30fps / 30.0秒、128 BPM・16小節）。制作の工程を8駅の路線に見立て、星（étoile）がカメラと一緒に駅から駅へ進みます。各駅では実際の制作素材を見せます。

| 時刻 | 駅 | 見せ方 | ツール |
| --- | --- | --- | --- |
| 0.0–1.9 | 全体 | HOW IT'S MADE、原画 → 完成のカード、8駅の路線図 → 1駅目へズーム | |
| 1.9 | 01 原画 | ポスターをスキャンし、文字のある場所すべてに枠。書き出した80行が流れる | Claude Code |
| 4.7 | 02 切り抜き | ポスター → 背景が消えて女性だけ → 緑背景 | Python |
| 7.5 | 03 動かす | 実際のプロンプトがタイプされ、生成された映像のコマが流れる | MiniMax H3 |
| 10.3 | 04 キー抜き | 走査線の左が透明に。マスクと、頭の位置の揺れ → 補正後のグラフ | Python / ffmpeg |
| 13.1 | 05 構成 | 8シーンの絵コンテと 8小節のルーラー（128 BPM・15.0秒） | Claude Code |
| 15.9 | 06 組み立て | 本編の実レイヤー5枚が3Dで分解 → 1枚に戻る、render(t) のコード | HTML / CSS / JavaScript |
| 18.8 | 07 音 | 本編の編曲どおりのピアノロール（どん底でドラムが消える） | Web Audio API |
| 21.6 | 08 書き出し | 0→450 のフレームカウンター、コマが積まれて MP4 に | Playwright / ffmpeg |
| 24.4–30.0 | 完成 | 全駅が点灯、完成版の早回し再生、ツール一覧（28.5秒以降は静止） | |

素材は `tools/making_assets.py`（原画・切り抜き・H3 の映像・キー抜き・完成版のコマ）と `tools/layers.mjs`（本編を透過レイヤー5枚に分けて撮影）で作り、
書き出しは `PAGE=making.html node tools/render.mjs dist/making-of.mp4`。

## 構成

```
index.html         舞台の骨組み（星とアイコンの SVG シンボル）
css/mv.css         レイアウトとタイポグラフィ
js/mv.js           カメラ・路線図・駅・キャラクター・文字・エンドカードを render(t) で描画
js/typo.js         文字を1字ずつ動かすエンジン（koi-mv と共通）
js/audio.js        WebAudio の BGM と効果音（声部は koi-mv と共通、Étoile 用の曲と効果音は scoreEtoile と cues.etoile）
assets/            キービジュアル原画、切り抜いた女性（woman.png）、動画生成用の緑背景（plate.png）
clips/             切り抜き済みのキャラクター映像（h3.webm：透過つき VP9）と位置情報
fonts/             Noto Sans JP / Montserrat / DM Mono / Cormorant Garamond（使用文字だけのサブセット）
tools/cutout.py    原画から女性を切り抜き、緑背景の静止画を作る
tools/key_clips.py 緑背景の映像からキャラクターを切り抜き、透過 WebM と位置情報を書き出す
tools/render.mjs   MP4 書き出し（Playwright + ffmpeg）
tools/stills.mjs   任意の時刻の静止画を書き出す
tools/fonts.py     画面に出る全文字からフォントのサブセットを作り直す
tools/vo.py        ナレーション（1ファイル）を行ごとに切り分けてシーンに配置し js/vo.js を書き出す
making.html        メイキング（js/making.js・css/making.css、素材は assets/making/）
```

## 書き出し

```sh
python3 tools/cutout.py                       # 素材の再生成（任意）
python3 tools/key_clips.py h3 --holes         # clips/h3.src.mp4 を置いてから実行（--holes: 髪やバッグのすき間の緑も消す）
NODE_PATH=$(npm root -g) node tools/render.mjs dist/etoile.mp4
```
