# H3 シリコンシャンプー LP モーション

LPデザイン（`assets/source.webp`）を、縦型 9:16（1080×1920 / 60fps / 約36秒）のLP風モーションに仕上げたもの。v3でKVを横顔の写真に変え、ゆったりしたテンポとディゾルブ中心のつなぎにした（v1は `index_v1.html`、25秒版のv2は `index_v2.html`）。

- 完成動画: `out/H3_LP_motion.mp4`（BGM付き）／ `out/h3_lp_motion_silent.mp4`（無音）
- ブラウザで確認: `index.html` をローカルサーバーで開くとループ再生（`npx serve` など。file:// だとWebGLが無効になる）

## 構成（v2 / 25秒版の参考。v3は同じ流れを約35秒にゆったり伸ばし、つなぎをディゾルブ・光漏れ・ゆっくりしたページ送りに変更）

| 時間 | 内容 | 動き・つなぎ |
|------|------|------------|
| 0.0–1.5 | イントロ | H3ロゴを線で描く → ロゴの形の窓からヒーロー写真へズームイン |
| 1.5–4.5 | HERO「シリコンを、選び直す。」 | 見出しが1文字ずつ出る、髪だけ微風、CTAが弾んで出る |

| 8.5–9.3 | つなぎ | 琥珀色の液体が画面を満たして製品へ |
| 9.0–12.0 | PRODUCT | ボトルが傾きながら着地、泡、ハイライト。最後はボトルに突っ込むズーム |

## 素材の作り方（元デザインへの忠実度）

- **写真（v2）**: 元画像の小さい人物写真は拡大すると崩れるため、ヒーローの女性を参照にして Runway（nano-banana-pro）で作り直した（`assets/gen2/`）。横顔・髪と手・艶髪・男性・使い方3ステップ・ガラス器具。
- **写真（v1から継続）**: ヒーロー写真とボトルは元画像を Real-ESRGAN で4倍化して切り抜いたもの（`src/upscale.py`, `src/prep_assets.py`）。
- **ヒーロー縦長写真**: 元写真を9:16キャンバスに置き、上下の空白だけをAIで補完。そのあと**元写真を同じ位置に戻して合成**しているため、顔・髪・服は元画像のまま（`assets/gen_hero_outpaint.jpg` → `assets/img/hero.jpg`）。
- **ボトル**: rembg（isnet）で切り抜き、ポンプ部分は手動マスクで補正。ラベルの小さい文字は元画像だと潰れて読めないため、同じ文言（SILICONE SHAMPOO／300mL / 10.1 fl.oz）をテキストとして重ねている。
- **背景プレート**: 製品シーンの水面背景と OLD/NEW の液滴テクスチャはAI生成（文字なし）。
- **文字**: 文言はすべて元デザインから一字一句そのまま。Webフォント（Shippori Mincho／Zen Kaku Gothic New／Josefin Sans／Cormorant Garamond）で組み直しているので、拡大してもにじまない。H3ロゴは元デザインの形を測ってSVGで描き直した。
- **音（v3）**: いただいたLyria 3のBGM（`assets/audio/bgm_lyria.mp3`、30.8秒）を、音程を変えずに1.12倍の長さに引き伸ばし、ブツ切れだった終わりに残響の余韻を付けて使用（`src/fit_bgm.py`）。効果音なし。合成版の予備は `src/audio_v3.py`。

## 再レンダリング

```bash
npm install

node src/render.mjs x 60 --frames 2.0,10.5   # 静止フレームの確認（out/stills/）
```
